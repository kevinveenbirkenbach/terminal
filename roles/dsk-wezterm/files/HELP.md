# WezTerm Help

Press q to close this help.

## Help

| Keys                      | Action                                   |
|---------------------------|------------------------------------------|
| F1                        | Search every key binding                 |
| Ctrl+Shift+F1             | Open this help in a new tab              |

## Tabs

| Keys                      | Action                                   |
|---------------------------|------------------------------------------|
| Ctrl+Shift+T              | New tab                                  |
| Ctrl+PageUp / PageDown    | Previous / next tab                      |
| Alt+Shift+Left / Right    | Move the current tab left / right        |
| Ctrl+Shift+R              | Rename the current tab                   |

## Panes

| Keys                      | Action                                   |
|---------------------------|------------------------------------------|
| Ctrl+Shift+Alt+V          | Split side by side                       |
| Ctrl+Shift+Alt+H          | Split top and bottom                     |
| Ctrl+Shift+Alt+W          | Close the current pane                   |
| Alt+Arrow                 | Go to the pane in that direction         |

## Folder Bookmarks

| Keys                      | Action                                   |
|---------------------------|------------------------------------------|
| Ctrl+Shift+B              | Bookmark the current folder              |
| Ctrl+Shift+O              | Pick a bookmark and open it in a new tab |

Bookmarks live in ~/.config/wezterm/bookmarks, one path per line.

## Window

| Keys                      | Action                                   |
|---------------------------|------------------------------------------|
| Drag the title bar        | Move the window                          |
| Double-click title bar    | Maximize / restore                       |
| Drag to top edge          | Maximize                                 |
| Drag to left / right edge | Fill the left / right half               |
| Drag a window border      | Resize the window                        |
| Alt+F10                   | Maximize / restore                       |
| Alt+F7 / Alt+F8           | Move / resize with the arrow keys        |
| Alt+Enter                 | Full screen on / off                     |
| Alt+Shift+Up / Down       | Background less / more transparent       |
